# Asyraff Azhar — Portfolio

A modern, responsive portfolio website showcasing my journey as a Data Engineer and AI practitioner.

## ✨ Features

- **Hero Typing Effect** — animated text cycling through roles
- **About Toggle** — switch between short and long bio
- **Skills Section** — cards with proficiency bars and tech tags (Data Science, ML, Vision, NLP, LLMs)
- **Project Slider** — drag-to-scroll + arrow button nav + keyboard support + scroll indicator dots
- **Smooth Scrolling** — nav links + "Back to Top"
- **Scroll-triggered Fade-in** — sections animate into view as you scroll
- **Fully Responsive** — mobile, tablet, desktop
- **SEO meta tags** — description, keywords, author

## 🛠 Tech Stack

| Layer    | Technology                              |
| -------- | --------------------------------------- |
| Markup   | HTML5 (semantic)                        |
| Styling  | CSS3 (custom + Bootstrap 5)             |
| Icons    | Font Awesome 6                          |
| Scripts  | Vanilla JS (no jQuery)                  |
